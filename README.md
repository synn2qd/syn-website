# SYN Studio

Premium esports design studio website. Single-file HTML — no build tools, no dependencies, no server needed.

## Deploy

### GitHub Pages (recommended)
1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Set source to `main` branch, `/ (root)` folder
4. Your site will be live at `https://yourusername.github.io/syn-studio`

### Drag & drop hosts
Upload `index.html` to [Netlify Drop](https://app.netlify.com/drop) or [Vercel](https://vercel.com) for instant deployment.

## Customisation

| What | Where in index.html |
|------|---------------------|
| Hero headline | Search `DESIGN THAT WINS` |
| Services & prices | Search `FROM $8` |
| Marquee tags | Search `HEADERS` in the scroll strip |
| Admin password | Search `synadmin` |
| Footer text | Search `PROOF OVER PROMISES` |

## Admin Panel
Navigate to the **Admin** tab and enter `synadmin` to manage orders. Change the password directly in the HTML before deploying.

## Order Portal
Clients visit the **Orders** tab and enter the password you assign them in Admin to unlock their delivery link.
